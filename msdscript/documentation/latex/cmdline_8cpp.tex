Processes command-\/line arguments. 

This function iterates through the command-\/line arguments provided by the user and performs actions based on specific flags:\+
\begin{DoxyItemize}
\item {\ttfamily -\/-\/help}:\+ Prints a help message and exits.
\item {\ttfamily -\/-\/test}:\+ Runs the test suite (Catch2) and exits.
\end{DoxyItemize}

If an unknown argument is encountered, it prints an error message and exits.
