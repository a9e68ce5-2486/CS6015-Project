Welcome to the MSDScript project documentation. MSDScript is a mathematical expression interpreter capable of parsing, evaluating, and manipulating mathematical formulas involving addition, multiplication, and variables.\hypertarget{index_features_sec}{}\doxysection{\texorpdfstring{Features}{Features}}\label{index_features_sec}

\begin{DoxyItemize}
\item {\bfseries{Expression Evaluation}}:\+ Calculate the integer value of expressions.
\item {\bfseries{Variable Substitution}}:\+ Replace variables with other expressions.
\item {\bfseries{Pretty Printing}}:\+ Format expressions with minimal parentheses based on precedence.
\item {\bfseries{Command Line Interface}}:\+ Support for testing and help commands.
